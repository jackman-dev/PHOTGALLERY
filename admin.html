사진 추가 방법

서버 없이 GitHub Pages에서 운영하는 방식입니다.

1. 사진 파일 올리기

GitHub 저장소의 photos 폴더에 사진 파일을 업로드합니다.

2. photos.json 수정하기

새 사진 정보를 photos.json 파일에 추가합니다.

[
  {
    "title": "Wedding Snapshot",
    "url": "./photos/wedding-01.jpg"
  }
]

3. 사이트 확인하기

변경 후 아래 주소에서 갤러리를 확인합니다.

https://jackman-dev.github.io/PHOTGALLERY/
